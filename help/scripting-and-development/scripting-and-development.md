# 腳本與開發

Adobe Substance 3D Sampler 支援透過 Sampler Python API 自訂外掛。 外掛對每位 Sampler 使用者都很有幫助——從自動化大型材質庫的材質建立，到自動設定新安裝，或新增功能。

安裝 Sampler 時，API 的完整文件會附帶。 你可以在 Sampler 裡面開啟 API 文件：

* 使用 Python API 文件>幫助...打開文件。

* [管理已安裝的外掛與腳本](manage-installed-plugins-and-scripts.md)
* [用 Python 和 QML 建立外掛](create-a-plugin-with-python-and-qml.md)
* [用 Python 建立腳本](../scripting-and-development/create-script-with-python/create-a-script-with-python.md)
