# 環境變數

本頁列出可用來覆寫應用程式預設行為的環境變數。

| 變數 | 說明 |
| --- | --- |
| **內容\_SAMPLER\_LICENSE** | 值：license.key檔案路徑 覆蓋應用程式載入授權檔案的位置。  **注意：**  3.0 之前的版本使用此變數名稱：**SUBSTANCE\_ALCHEMIST\_LICENSE** |
