# 工具

工具是 Sampler 中最大的一組篩選器，因此很難理解它們的差異。 理解工具過濾器最簡單的方法是它們用來修正材料的技術問題。

許多工具可用於影像和材料。 通常在將影像轉換成素材前，先用濾鏡校正是個好主意。 先校正影像後，工具只需在單一通道上工作——影像資料;而校正材料則需校正多個通道。 僅修正單一通道可減少所需處理量，但同時也降低錯誤的可能性。

工具濾鏡通常會在 2D 視圖&#x200B;**中使用把柄和其他控制**，因此在使用工具時，讓 **2D 視圖**&#x200B;可見通常是個好習慣。
