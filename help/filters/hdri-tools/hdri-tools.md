# HDRI 工具

>[!IMPORTANT]
>
> 未來變革
> 
> 隨著 Sampler V5.2 的發行，環境燈光與網格的支援將被移除。 移除環境燈同時也包括移除HDRI工具與濾鏡。

HDRI 工具區塊中的濾鏡是專門用於環境燈的工具。 HDRI 代表高動態範圍影像（High Dynamic Range Image），但通常用來指用於製作環境光源的全景影像。 在傳統軟體中修改全景影像可能較為困難，因為球形 3D 資訊必須映射到 2D 影像檔案——Sampler 中的 HDRI 工具即刻設計此點，因此在 HDRI 上補丁和添加燈光會容易許多。
