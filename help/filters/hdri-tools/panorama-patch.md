## 說明

修補環境燈中的問題區域。 全景補丁會自然地維持變換和傾斜，以配合背景表面。

## 參數

**基本參數**

* **補丁半徑**：0-1\
  調整補丁的大小。
* **Patch Contrast：** 0-1\
  調整貼片邊緣的硬度。
* **補丁輪替**：0-1\
  旋轉補丁區域。

## 使用指南

將&#x200B;****&#x200B;全景補丁濾鏡&#x200B;**加到圖層堆疊頂端，然後在 2D 視圖**&#x200B;中使用 handle 調整來源和補丁位置。
