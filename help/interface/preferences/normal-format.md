# 一般格式

法線貼圖使用 <b>DirectX</b> 格式處理，並維持<b> OpenGL</b> 工作流程，透過改變法線格式偏好來匯入和匯出 OpenGL 格式。

*預設：DirectX*

一般格式偏好會影響：

* 影像匯入圖層
* 匯出

## 影像匯入圖層

匯入法線貼圖時，法線格式會設定為偏好設定中所選格式。

### 匯出

#### SBSAR與SBS

正常格式是裸露的參數。 這個參數可以由主機應用程式調整，以產生所需的標準格式。

#### 影像格式

法線會匯出到偏好設定中所選格式。
