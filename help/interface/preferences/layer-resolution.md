# 圖層解析度

圖層解析度系統讓你能完全控制圖層堆疊中每一層的解析度。 圖層可以取你文件大小的解析度，或是下面圖層的解析度。

解析度會顯示在每個圖層上，方便視覺化任何作品會如何受到素材解析度的影響。

這能讓你提升材料品質，但要注意較高解析度會影響素材的效能。

![圖層面板與屬性面板顯示圖層解析度](../../assets/LayersPanelAndPropertiesPanel.png)

只需一鍵，你就能從工作解析度切換到更高解析度，視覺化準備好匯出的最終素材。

![切換所有層解析度](../../assets/Switch_All_Resolution.gif)
