# 介面

Sampler 的工作區由 2D 與 3D 視窗、左右側邊欄，以及一系列面板組成。 每個面板都有特定用途，因此不同面板在創作過程中不同階段都很有用。

## 自訂工作區

Sampler 的工作區完全可自訂，你可以找到最適合自己的版面配置。 如果你想把面板重設成預設配置，可以用 **視窗>重置成預設配置**。

## 重新排列面板

點擊並拖曳面板標題開始移動。

你可以將面板停靠在視窗或其他面板的邊緣：將面板拖到你想要停靠的邊緣，藍色高亮導覽就會出現。 當你看到線條出現時，放下面板來接駁。

## 開關面板

用面板右上角的 X 鍵來關閉它。 封閉面板則存放在側邊欄。

要重新開啟面板，請點擊左右側邊欄中該面板的相關圖示。 這會暫時打開面板。 把面板拉出來，讓它永久保持開啟。

## 申請選單

應用程式選單列&#x200B;**顯示**&#x200B;目前的專案名稱。同時也包含 **檔案**、 **編輯**、 **視窗**、 **說明**&#x200B;和 **授權** 選單。

使用 <b>檔案</b> 選單建立新專案、開啟現有專案，或儲存或匯出您目前的專案。

使用 <b>編輯</b> 選單來撤銷並重做動作，或開啟 [偏好設定](../interface/preferences/preferences.md)。

使用 <b>視窗</b> 選單將工作區重設為預設配置。

使用 <b>說明 </b>選單了解更多關於 Sampler 的資訊或如何修復問題。
