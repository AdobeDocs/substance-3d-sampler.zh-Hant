# 材質創建預設

材料製作範本為具有進階物理行為的建材提供預設起點。 每個範本都會配置材質模型、啟用通道，以及特定表面所需的預設參數，讓你能快速建立複雜材質，同時完全掌控結果。 在建立新材質時，範本可用，且可用於 OpenPBR 和 ASM 材質模型。

![新增素材視窗](../../assets/6.0_materialPresets.png)

>[!TIP]
> 你可以在這裡了解更多如何利用毛絨、底層及塗層通道 [來打造先進材料。](../../features-and-workflows/create-advanced-materials/advanced-materials.md)

## 從範本建立材質

使用範本製作材料：

打開「建立新素材」對話框。 從預設或自訂分頁中選擇範本。 調整材質設定（名稱、解析度、材質模型、通道）。 點擊建立開始處理已設定的素材。

所選範本定義了材質的初始結構，包括啟用哪些通道，以及它們如何在圖層堆疊中設置。

## 預設類別

### 預設範本

預定義範本是即用的材質設定，設計用以涵蓋常見的物理材質行為。 它們會根據每個使用情境編碼最佳實務與推薦的通道配置。 可用的預設範本包括：

- 基底材質：標準的物理基礎材質，啟用常用通道。 使用此範本用於不需要特殊行為的簡單或通用材料。

- 各向異性 將材料配置為方向依賴反射，適用於拉絲金屬或具有定向微細節的表面。

- 塗層在基材表面增加第二層反射層，實現透明塗層或清漆效果。

- 絨毛 使柔和、散射光線的表面效果成為布料、纖維或具有天鵝絨外觀的材料。

- 地下 啟動地下光傳輸，適用於蠟、塑膠或有機表面等光線穿透表面以下的材料。

- 透明材質配置以具備光線透透性，適用於玻璃狀或薄透明材料。

每個預設預設會自動設定所需的通道與預設值，減少手動設定與技術複雜度。

### 自訂預設

自訂預設允許你重複使用自己的材質配置。 你建立的任何材質預設都可以儲存成自訂範本，並會出現在自訂標籤中。 這使得跨專案或團隊能夠一致地建立素材，並使用共用標準與管道配置。

## 預設細節

預設細節面板顯示並控制用於建立新材質的設定。

### 資產名稱

定義將被建立的材料資產名稱。

### 解決方法

控制材質貼圖的預設解析度（寬度與高度）。 此解析度適用於所有啟用的通道，當素材被建立時。

### 材質模型

指定材料所使用的材料模型：

OpenPBR 用於現代、標準化的實體基礎工作流程 ASM 以與現有管線相容

所選模板會適應所選材質模型。

### 加入基礎材料

啟用後，Sampler 會使用與所選範本相容的基礎材質建立基礎填充圖層。 這能立即提供視覺效果與實用起點。 基礎材質同時適用於 OpenPBR 與 ASM 材質模型。

### 套用預設縮圖值

啟用時，材質會以產生範本預覽縮圖的值初始化，而非中性預設值。 這有助於展示範本的預期行為，並提供一個可開始建構的視覺基礎。

### 編輯列表

點擊 **編輯清單** ，在建立素材前先自訂頻道組合。 你可以根據需要啟用或停用頻道，或將設定存成新的自訂範本。
