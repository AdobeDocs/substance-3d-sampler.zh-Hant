# 滑桿

![](../../assets/sliders-basic.gif)

遊戲有可動畫化一到多個滑桿的選項。 滑鼠滑鼠時按 **Ctrl** ，會跳出 **播放** 圖示啟動動畫。

當你將滑鼠懸停在動畫滑桿時，**按 Ctrl** 鍵可以暫停動畫，暫停&#x200B;**&#x200B;**&#x200B;圖示會顯示暫停這個滑桿的動畫。

如果你想暫停所有滑桿，請按 **P**。要重新啟動，請再按 **一次 P** 。
