# 側欄

Sampler 有兩個側邊欄，左側 **邊欄** 和 **右側側邊欄**。

![](../assets/Sidebars.png)

## 左側邊欄

從 **左側側邊欄** 您可以：

* **新增與匯入內容**：匯入圖片並選擇它們如何整合到您的專案中。
* **瀏覽 3D 資產**：在 Creative Cloud 桌面版中存取數千個來自 Substance 3D 資產的素材。
* 快速操作&#x200B;****：一組快速達成特定目標的行動。[了解更多關於快速動作的資訊&#x200B;****](../features-and-workflows/quick-actions.md)**。**
* 快速存取篩選器。
* 關閉後重新開啟下列面板：
  * **快速動作面板**。
  * 專案 **小組**。
  * **資產面板**。
  * **通道設定面板**。

如需更多關於左側 **側邊欄**&#x200B;可用篩選器的資訊，請參閱「 [工具與小工具](tools-and-widgets/tools-and-widgets.md)」。

## 右側邊欄

**右側側邊欄**&#x200B;在關閉時可放置以下面板：

* **圖層面板**。
* **屬性面板**。
* **「曝光參數」面板**。
* **實體尺寸面板**。
* **元資料面板**。
* **匯出面板**。

## 從側邊欄新增篩選器

**左側側邊欄**&#x200B;提供快速存取篩選條件的功能。將滑鼠移到篩選器圖示上會顯示篩選器名稱，點擊篩選器會立即將其加入你的堆疊中。

您也可以在篩選條件上按右鍵，以查看相關篩選器的清單。 例如，右鍵點擊「平鋪&#x200B;**」篩選器，就能進入**「自動平鋪&#x200B;**」和**「設為平鋪&#x200B;**」的篩選**&#x200B;條件。

>[!NOTE]
>
> 使用&#x200B;**滑鼠右鍵選單**&#x200B;新增篩選器時，側邊欄&#x200B;**中的原始篩選**&#x200B;器會被替換為最近使用的篩選器。
>
> 例如，在下方動畫中， **會顯示「均衡」濾鏡** 。 在右鍵點擊並新增&#x200B;**摺痕去除器濾鏡**&#x200B;後，**側邊欄**&#x200B;中的&#x200B;**均衡濾鏡**&#x200B;會被&#x200B;**摺痕去除器濾鏡**&#x200B;取代。
>
> ![](../assets/quick-filter-replacement.gif)
