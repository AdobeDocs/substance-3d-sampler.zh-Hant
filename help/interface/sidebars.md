# 側欄

Sampler 有兩個側邊欄，分別是 **左側邊欄** 和 **右側邊欄**。

![](../assets/Sidebars.png.img.png)

## 左側邊欄

從 **左側邊欄** 你可以：

* **新增與匯入內容**：匯入圖片並選擇如何整合到你的專案中。
* **瀏覽 3D 素材**：在 Creative Cloud Desktop 中存取數千個來自 Substance 3D 資產的素材。
* 存取 **快速行動**：一組快速達成特定目標的行動。 [了解更多關於快速行動的資訊&#x200B;****](../features-and-workflows/quick-actions.md)**。**
* 快速將濾鏡加入圖層堆疊：
  * **裁切：**&#x200B;在 2D 視圖&#x200B;**中使用手柄**&#x200B;裁切影像和材質。
  * **透視轉換：** 在 2D 視圖中修正用手柄 **修正透視錯誤。**
  * **變換：** 在 2D 視圖中調整影像和材質 **的大小。**
  * **複製印章：**&#x200B;在2D視圖&#x200B;**中繪製區域**&#x200B;以修正接縫或其他問題。
* 關閉後重新開啟以下面板：
  * [**快速行動面板**。](panels/quick-actions-panel.md)
  * [專案 **小組**。](panels/project-panel.md)
  * [**資產面板**。](panels/assets-panel.md)
  * [**頻道設定面板**。](panels/channel-settings-panel.md)

欲了解更多左側側邊欄篩選&#x200B;**器的資訊，請參閱[工具與小工具](tools-and-widgets/tools-and-widgets.md)。**

## 右側邊欄

**右側側欄**&#x200B;關閉時可放置以下面板：

* [Layers **面板**。](panels/layers-panel.md)
* [**屬性面板**。](panels/properties-panel.md)
* [**暴露的參數面板**。](panels/exposed-parameters-panel.md)
* [實體 **尺寸面板**。](panels/physical-size-panel.md)
* [元 **資料面板**。](panels/metadata-panel.md)
* [**出口面板**。](panels/share-panel.md)
