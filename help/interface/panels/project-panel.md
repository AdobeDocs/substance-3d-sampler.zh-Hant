# 專案小組

![](../../assets/Project-panel-gen.png)

Sampler 裡的專案就像可以儲存多個資產的套件。 **專案面板**&#x200B;顯示構成你目前專案的材料。

專案面板頂端的控制項允許你在目前專案中新增或管理材料：

* 請使用新增&#x200B;**&#x200B;**&#x200B;按鈕開啟&#x200B;**材料預設選單**，並將新材質加入你的專案。
* 使用 **複製** 按鈕來複製目前選取的素材。
* 使用 **「重新命名** 」按鈕來重新命名目前選取的素材。
* 使用 **刪除** 按鈕刪除目前選取的素材。

>[!NOTE]
>
> 你也可以右鍵點擊任何素材來重新命名、刪除或複製它。

點擊其中一個資產可以在視埠&#x200B;**中載入**，或將材質拖到&#x200B;**圖層面板**，讓它用於其他材質。
