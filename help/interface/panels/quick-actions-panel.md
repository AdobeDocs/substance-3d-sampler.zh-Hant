# 快速行動面板

![](../../assets/quickactionpanel.png)

[快速動作](../../features-and-workflows/quick-actions.md) 是一系列功能與工作流程，讓你只需幾次點擊就能執行強而有力的動作。 使用 Quick Actions 來建立材質、建立專案，或將你需要的圖層加入現有堆疊。

從快速動作面板點擊快速動作，可以根據快速動作類型新增資產或新增資產。 快速行動分為以下幾類：

* **最近**：存取你最近使用的快速操作。
* **處理圖片**：匯入、轉換或調整圖片。
* **提升材質掃描**：對齊、精煉或平鋪掃描後的材質以獲得更好的結果。
* **從影像**&#x200B;建立材質：將必要的圖層加入圖層堆疊，將一張或多張圖片轉換成材質。
* **從零**&#x200B;開始建立材質：建立一個帶有起始圖層的新材質資產。

當你將滑鼠移到快速動作上時，可以使用選項按鈕，該按鈕會出現：

* **將快速動作套用** 到圖層堆疊上。
* **透過對話設定** 快速動作。
* **使用選定的快速動作建立新資產** 。
* **使用選取的快速動作建立新專案** 。
