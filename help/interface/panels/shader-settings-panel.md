# 著色器設定面板

![](../../assets/Shader-settings-panel-gen.png.img.png)

著 <b>色器設定面板</b> 是你可以設定著色器如何在 3D 視口中渲染你的網格資產的地方。

## 材料參數

材質參數可以讓你調整目前材質被著色器渲染的方式。

| 參數名稱 | 說明 |
| --- | --- |
| 標準尺度 | 調整法線貼圖的強度或強度。 |
| 結合法線與高度 | 切換高度貼圖和法線貼圖是否合併成同一張貼圖。 |
| 高度 | 改變排水高度的基準高度。 |
| 發射強度 | 調整發射貼圖的強度。 |
| 次表面散射 | 切換 Subsurface 散射的開關。 |
| 折射率 | 調整光線折射在表面上的角度。 |
| 毛髮折射率 | 調整光線從表面塗層折射的角度。 |
| 毛髮正常鱗片 | 針對表面塗層調整法線比例。 |
