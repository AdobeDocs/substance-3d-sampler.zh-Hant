# 屬性面板

![物業面板](../../assets/Properties-panel-gen.png)

屬性面板&#x200B;**會**&#x200B;顯示你在&#x200B;**圖層面板**&#x200B;中選取的圖層的參數和屬性。了解參數的作用最好的方法是調整它們，看看它們對資產的影響。

屬性面板中出現&#x200B;**的參數取決於你在圖層面板**&#x200B;中選擇&#x200B;**&#x200B;**&#x200B;的內容。有時候一個圖層會有多組可自訂屬性，例如不在堆疊底部的材質圖層會有混合屬性。 圖層堆疊中的每個圖示代表一組不同的屬性和參數。 對於同時擁有材質屬性和混合屬性的材質圖層，該圖層上會有兩個圖示。

## 申請到......

**屬性面板**&#x200B;的&#x200B;**「套用到**」區塊可以讓你控制當前圖層影響的通道。和其他屬性一樣，通道設定會根據選擇圖層還是混合而有所不同。

![屬性通道中的「套用到...」區塊讓你控制目前過濾器影響的通道。](../../assets/6.0_AppliedTo.png)

預設情況下，大多數材質和濾鏡的所有頻道都已開啟。 有些濾鏡，如亮度或鮮度，只影響單一頻道。 當濾波器只影響單一頻道時，你可以在圖層名稱旁邊看到受影響的頻道。

![圖層面板的截圖，頻道標示被劃線。](../../assets/6.0_LayerChannelSpecifier.png)
