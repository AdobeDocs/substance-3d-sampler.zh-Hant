# 資產面板

![](../../assets/Assets-panel-gen.png.img.png)

**資產面板**&#x200B;包含你可以用來打造創作的資產。Sampler 包含一系列材質、濾鏡和材質產生器，幫助你入門。

**資產面板**&#x200B;有一些控制功能，可以幫助組織和尋找資產：

* 使用搜尋欄快速找到資產。
* 依類型篩選資產。
* 依類型或類別分類資產。
* 在清單與圖示視圖之間切換。

## 將資產加入資產面板

要將自己的資產加入資產面板，請點擊資產面板&#x200B;**右**&#x200B;下角的 +**鍵**。瀏覽到你資產的位置，選取它，然後點擊 **開啟**。 你可以把自訂資產 **從素材面板** 拖到垃圾桶上移除。

## 啟用額外通道

當你從資產面板拖放材質到圖層堆疊時，可能會被提供啟用額外通道的選項。 當素材輸出一個目前未在資產中啟用的通道時，會提供此服務。 如果你想充分利用材料的複雜度，比如某些各向異性效果或塗層，你可能會想啟動它。

![當材質加入圖層堆疊時，通道啟動彈窗](../../../help/assets/sampler_assets-panel_additional-channels-activation.png)

>[!NOTE]
>
> 只有自訂資產可以在資產面板&#x200B;**中刪除**。無法刪除 Sampler 的預設資產。
