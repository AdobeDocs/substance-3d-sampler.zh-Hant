# Exposed Parameters 面板

![](../../assets/ezgif-com-gif-maker-7.gif)

**Exposed Parameters面板則**&#x200B;包含從&#x200B;**屬性面板中暴露的參數。**

彩色點用來幫助視覺化該參數連接到哪一層。 空點表示參數來自混合圖層。

![](../../assets/ezgif-com-gif-maker-1.gif)

有幾種方式可以與暴露的參數互動：

| 動作 | 如何 |
| --- | --- |
| 解除參數的曝光 | 右鍵點擊參數，選擇「Unexpose」。 |
| 編輯參數的標籤 | 右鍵點選參數並選擇「編輯」，輸入新的標籤。 |

你可以像平常在 **屬性面板一樣互動所有參數。** 變更將反映在 3D 視窗中。
