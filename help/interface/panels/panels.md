# 面板

Sampler 中的每個面板都有特定用途。 預設情況下，只有以下四個面板會開放：

* **專案面板**：允許你管理目前已開啟專案中的資產。
* **資產面板**：存放起始內容和其他資產庫，供你用來製作資產。
* **圖層面板**：顯示所選資產的圖層堆疊。
* **屬性面板**：顯示目前選取圖層的屬性與參數—— **圖層** 面板 **與屬性** 面板會一起使用

這些面板最常用於製作資產的過程中。

剩下的面板預設是關閉的，並保留通常不需要頻繁更改的選項和控制。 你可以從左右側邊欄進入這些面板。

* **實體尺寸面板**：設定掃描樣本與影像的實際尺寸。
* **元資料面板**：透過新增描述或更改所選資產的作者名稱來編輯元資料。

要在任何時候回到預設工作區的配置，請使用 **視窗> 重置為預設配置**。
