# 2D 與 3D 視窗

![](../assets/main-3d-viewport-5.png)

視窗&#x200B;**會**&#x200B;顯示你目前的資產。在 V **&#x200B;**&#x200B;iewport **的頂端**，你可以看到資產名稱和更改&#x200B;**視窗**&#x200B;外觀的選項。利用這些選項來：

* 改變資產的寬度和高度（像素單位）。
* 可以同時顯示 <b>2D 視圖</b>、 <b>3D 視圖</b>，或同時顯示 <b>2D </b>與 <b>3D 視圖</b>。
* 把分割視圖</b>切換<b>成水平顯示。
* 交換 <b>3D 和 2D 視角</b>。
* 在標準視窗和全螢幕視窗之間切換。

![](../assets/screenshot-2023-01-25-at-16-23-09.png)

## 3D 檢視

<b>3D 視窗</b>有兩個工具列，可以讓你調整資產在視窗</b>中的<b>呈現方式。預設情況下，這些工具列會出現在 3D 視口</b>的右上角和中央下方<b>。

![] ()

>[!NOTE]
>
> <b>3D 視窗</b>工具列可以重新定位：
> 
> * 你可以拖動工具列上方或左側的把手來移動工具列。
> * 雙擊工具列上方或左側的把手，可以在水平和垂直配置間切換。
> * 點擊工具列底部或右側的雙重倒V形符號，可以縮小工具列。

3D 視窗</b>右上角<b>的工具列有聚焦於視窗外觀的控制：

* <b>視角</b>：調整相機設定，如視野或投影模式。 另外，也要改變格子和背景顏色。
* <b>網格</b>：選擇不同的網格來顯示你的材質資產，或查看環境光源資產的細微差異。
* <b>材質</b>：改變網格貼圖的位置和平鋪。
* <b>位移</b>：調整位移的品質與強度。
* <b>燈光</b>：選擇並調整環境燈，包括開啟陰影和地面平面等設定。
* <b>切換路徑追蹤</b>：路徑追蹤是一種渲染技術，能提供照片級真實效果，提升資產的外觀。 不過，路徑追蹤可能計算量大，這裡你可以根據需求開啟或關閉路徑追蹤。

>[!NOTE]
>
> 開啟陰影以改善視窗視覺效果。 關閉陰影以提升取樣器效能。

![] ()

3D 視窗</b>底部中央<b>的工具列顯示以下資訊與控制項：

* <b>幀時間/FPS：</b>這些數值顯示材質的效能。
* <b>框架物件</b>：將相機置中於網格中心。
* <b>改變向上軸</b>：改變被視為向上的軸。 這有助於修正匯入網格的問題。
* <b>擺放</b>：改變網格相對於地面平面的位置。
* <b>複製快照</b>：快速將當前 <b>3D Viewport</b> 的影像複製到剪貼簿。
* <b>儲存快照</b>：將 3D Viewport</b> 的快照<b>儲存到影像檔案中。
* <b>3D 視圖控制</b>：在 3D 視窗中快速查看相機控制。

![] ()

## 移動攝影機

視窗使用攝影機來渲染 3D 視圖。 你可以移動相機來改變視角，從不同角度看到你的創作。

| 捷徑 | 運動 | 說明 |
| --- | --- | --- |
| 點擊+拖曳 | 環繞 | 旋轉攝影機。 無法拍攝攝影機。 |
| 右鍵 + 拖曳 | 推鏡 | 前後移動攝影機。 |
| 中鍵點擊 + 拖曳 | 平移 | 將攝影機向左、向右、上、下移動。 |

<b>2D 視角</b>是二維的，因此沒有軌道選項。右鍵 + Alt + 拖曳會放大縮小，中鍵 + Alt + 拖動則是平移。

在 3D 和 2D 視圖<b></b></b>中<b>，都使用 <b>F</b> 鍵來聚焦你的資產。如果你忽略了 3D 資產或 2D 空間，這很有幫助。

## 2D 視角

![] ()

預設情況下，只有 <b>3D 視角</b> 可見，不過 <b>2D 視圖</b> 可以包含許多有用的資訊和某些濾鏡的控制。

要開啟 <b>2D 視圖</b> ，請使用視窗右上角的 <b>「檢視選擇」按鈕 </b>。 你也可以用快捷鍵 <b>2</b>快速切換到 <b>2D視角</b>。

開啟 <b>2D 視角 </b>後，會出現一些新選項：

* 在 2D 視圖&#x200B;**右**&#x200B;上角，使用下拉選單更改可觀看的頻道來源。

  * 圖層輸入顯示輸入到所選圖層的通道
  * 圖層輸出顯示所選圖層輸出的頻道
  * Material Outputs 顯示的是頂層輸出的通道，且不受圖層選擇影響。
* 在 2D 視圖&#x200B;**的**&#x200B;底部，你可以：

  * 請參閱所選通道的解析度。
  * 選擇頻道以 2D 視圖觀看。
  * 請參閱所選材質通道的色彩通道與位元深度。
