# 開機時當機 - 舊版 OBS 版本

由於安裝了舊 [版 OBS，](https://obsproject.com/fr) 應用程式啟動時可能會當機。

要解決這個問題，要麼更新 [OBS 版本](https://obsproject.com/fr/download) ，要麼卸載。
