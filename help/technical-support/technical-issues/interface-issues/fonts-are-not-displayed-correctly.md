# 字型顯示不正確

如果你使用 Windows 10 Enterprise 並使用 [「阻擋不受信任字型」功能](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise)，可以依照此 [教學](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html) 將 Sampler 排除在不可信字型阻擋應用程式清單中。
