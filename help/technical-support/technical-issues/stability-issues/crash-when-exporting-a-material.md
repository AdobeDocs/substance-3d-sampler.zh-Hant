# 匯出材料時當機

匯出時可能會在匯出 Sampler 中建立的材質時當機。 這種當機通常是因為在匯出流程開始時，GPU 缺乏可用的 VRAM（尤其是使用 Delighter 濾鏡的材質時）。

降低匯出解析度並關閉其他應用程式，可能有助於釋放部分記憶體，讓匯出完成。
