# 使用 Image 轉為 Material 或 Delighter 時會當機

**Image To Material（AI 驅動）**&#x200B;和 **Delighter** 濾鏡需要大量可用的 VRAM（至少 1GB）。

如果你的顯示卡只有 2GB VRAM，且解析度為 2K/4K，我們無法分配足夠記憶體執行濾波器，可能會發生當機。
