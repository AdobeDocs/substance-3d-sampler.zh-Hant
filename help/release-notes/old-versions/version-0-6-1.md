# 版本 0.6.1

發行日期： **2019/05/07**

補充：

* [引擎]Substance Engine 更新以相容最新 Substance Designer 版本
* [授權]首次安裝時更新授權資料夾
* [圖層]隨時重新載入你的圖層堆疊以更新自訂過濾器

修正：

* [資料相容性]預防性修正以限制升級時的資料損壞

已知問題：

* 不建議在同一材料中使用多個 Delighters（甜點）
* Delighter 在較舊的 NVIDIA 驅動程式（低於 400.x）時會當機
* 不建議快速切換 Delighter 舞台
* 自訂環境匯入可能會變成黑色
* Tif 影像在 Image 匯入圖層的屬性面板中沒有顯示
* 在滑桿中輸入特定值時，可以忽略逗點或點
