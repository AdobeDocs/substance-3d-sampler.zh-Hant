# 版本 2020.1（2.1）

**Substance Alchemist 2020.1「提拉米蘇」** 讓你能直接匯出素材，直接打包給渲染器和遊戲引擎。 預設有 15 種匯出預設，例如 Unity HDRP、Unreal Engine 4、Blender、Vray-Next 等。

它新增了設定檔和更新檢查器的控制功能。

發行日期： *2020年3月12日*

## 主要特色

### 新的出口窗口

![](../../assets/header-exporter.png)

匯出視窗已重新設計，新增了多項新功能：

* **使用匯出預設來打包特定渲染器或遊戲引擎** 的貼圖。現在可以在匯出過程中選擇一個設定，這些預設會轉換、打包並命名給特定第三方應用程式的貼圖。 此轉換結果會顯示在介面右側的通道清單中。\
  新匯出器預設包含以下預設：

  * 虛幻引擎4
  * Unity 標準
  * Unity HDRP
  * Blender Cycles/伊布
  * 阿諾德 5
  * Corona 渲染
  * 逃脫
  * 關鍵攝影9
  * 紅移
  * Vray Next
  * 鏡頭工作室
  * Spark AR 工作室
  * PBR 金屬粗糙度帶來的 PBR 鏡面/光澤感

  ![](../../assets/exporter-preset-list.png)
* **建立一個包含材料名稱的子資料夾**\
  當將多個材料匯出到同一位置時，現在可以建立子資料夾
* **匯出設定會被儲存並還原，並伴隨下一次匯出**\
  為了方便起見，重新開啟匯出視窗也會重複使用之前使用的匯出設定。 讓重新匯出材料變得更簡單且快速。
* **建立、匯入並管理自訂匯出預設**\
  也可以建立自訂匯出預設。 想了解如何建立和管理這些工具，請參考以下文件頁面：

  * [管理自訂預設](https://helpx.adobe.com/tw/substance-3d/unlisted/documentation/sadoc/creating-and-importing-custom-presets-188976295.html)
  * [管理預設](../../getting-started/export/managing-presets.md)

### 應用程式配置

![](../../assets/header-config.jpg)

（照片由[Fabian Grohs](https://unsplash.com/@grohsfabian?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText) 在 Unsplash[&#128279;](https://unsplash.com/?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText) 提供）

現在可以用設定檔來設定《物質煉金術師》。 這使得跨電腦（例如工作室內）的應用程式設定變得更為簡單。 設定檔定義了預設資源和連結資料夾清單。

想了解更多如何建立和使用設定檔，請參閱專門的文件 [頁面](https://helpx.adobe.com/tw/substance-3d/unlisted/documentation/sadoc/resources-configuration-file-188976187.html)。

### 其他改進

![](../../assets/header-checker.png)

本版本提供了幾項新的工作流程改進：

* **2D 視圖焦點**\
  現在可以使用「F」快捷鍵來重置並置中 2D 視圖，與 3D 視圖相同。
* **重新開放上一個專案**\
  為了讓內容創作更簡單、更快速，應用程式現在會重新開啟最後使用的專案。 現在，Create Lab 也是開啟應用程式時的預設模式。
* **更新檢查器設定**\
  請定義您是否希望收到新版本的通知。 更多資訊請參閱專門的文件 [頁面](../../technical-support/configuration/update-checker.md)。

### 新內容

![](../../assets/header-content.jpg)

我們改進了一些篩選條件，也更新了起始內容：

* **新入門材料**\
  我們用新材料替換了幾樣現有材料，以下是新材料清單：
  * Alcantara 超細纖維
  * 地毯地板
  * 懸崖岩
  * 銅
  * 裂痕泥土
  * 粗糙演繹
  * 兵馬俑
  * 羊毛布料
  * 織布
* **使用點陣圖 2 材質濾波器的金屬控制**\
  Bitmap 2 材質濾波器已更新，能更好地控制金屬通道。 現在可以使用自訂的點陣圖輸入，或定義統一的顏色。
* **改良調整濾波器**\
  調整過濾器現在可以搭配設定為使用 PBR 工作流程的 Specular/Glossiness 專案一起使用。
* **新的圖譜散射參數**\
  我們新增了一些參數，以便更好地控制元素與下方材質高度圖的融合。
