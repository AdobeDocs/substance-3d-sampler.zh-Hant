# 版本 3.0

**Substance 3D Sampler 3.0.0** 是 Substance Alchemist 的新名稱，因為它已經連接到 Adobe Creative Cloud。 它帶來了完整的介面重製、支援建立環境燈光、全新重製與新濾鏡、送出功能以及 ASM 著色器支援。

上映日期： *2021年6月23日*

## 主要特色

### 新介面與面板管理

有了新名字，也帶來了新的面貌。 Sampler 的使用者介面已全面改造，允許更多自訂與更方便的存取。

![](../../assets/ui-dualscreen.jpg){width="600px"}

面板可以插拔底座，讓你能充分利用雙螢幕配置。

### 新專案工作流程

![](../../assets/ui-project-panel.png)

Sampler 現在能支援專案。 [專案面板](../../interface/panels/project-panel.md)讓你可以管理並分組每個專案的資產。專案會儲存在 Substance Sampler 檔案中，方便分享。

### 新資產小組

![](../../assets/image2021-6-22-17-58-15.png)

[資產面板](../../interface/panels/assets-panel.md)是資源面板的新通用設計，結合了你的收藏。

* 3 個區塊：入門資產 + 你的資產 + 已連接的本地資料夾
* 新增資產類型支援：濾鏡與圖片
* 狹窄/廣角視野
* 篩選與搜尋篩選

### 新環境光源創作

![](../../assets/idl.jpg){width="600px"}

Sampler 現在讓你不只製作材料。 環境燈是一種新型資產，擁有 [自己的一套濾鏡](../../filters/hdri-tools/hdri-tools.md)。 可以從[包圍後的 360 度照片開始，從零](../../filters/hdri-tools/shape-light.md)開始製作環境燈[&#128279;](../../filters/hdri-tools/hdr-merge.md)，或[編輯現有的 HDR 檔案](../../filters/hdri-tools/nadir-patch.md)。

### 重新設計與新濾鏡

![](../../assets/filter-all-filters.jpg){width="600px"}

所有現有過濾器均已重新設計：

* 支援規格/光澤通道。
* 支援自訂遮罩
* 標準化參數名稱
* 幾乎所有濾鏡都有圖示

調整濾鏡依功能拆分成多個濾鏡，以模仿 Photoshop：

![](../../assets/filter-adjustment-filters.jpg)

新增了幾個篩選器：

* [曲速變形](../../filters/tools/warp-transform.md)
* [編織](../../filters/generators/weave.md)
* [小組](../../filters/generators/panel.md)

### 新增的「送出」功能

![](../../assets/image2021-6-22-18-2-10.png)

Sampler 現在 [可以輕鬆地與 Substance 3D Painter 和 Stager 共享材質與光環境](../../interface/panels/share-panel.md)，只需一鍵即可。

### 全新即時渲染引擎

* 支援ASM材質，使得在擁有更多材料管道的應用程式間呈現一致的外觀。
* 切換兩個 [即時引擎](https://helpx.adobe.com/tw/substance-3d/unlisted/documentation/sadoc/viewer-settings-188973164.html)
* 能夠控制網格上的預設材質

### 一般改良

* 新語言
* 應用程式響應性
* 非正方形材質支援
* 工具 還原/重做
* 在影像匯入圖層中為圖片指派自訂使用方式
* 重置參數值
* 在 Windows 工作列中匯出進度
