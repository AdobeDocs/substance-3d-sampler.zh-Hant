# 0.5.3

發行日期： **2019/03/19**

補充：

* 在資源面板中依材料名稱搜尋
* [使用者介面]Clone Tool 新 UI 附有筆刷大小視覺化功能
* [使用者介面]選擇並刪除隱藏關卡
* [使用者介面]新文字欄位使用者介面
* [求助]存取物質來源、物質分享及物質學院網站
* [內容]新增預設材料，包含產生器和地圖集
* [內容]點陣圖至材料更新
* [內容]最新消息
* [內容]Rust 更新
* [內容]新壓紋濾鏡
* [內容]新刺繡濾鏡
* [內容]新 Erode 濾鏡
* [內容]新碎石發電機
* [內容]新油漆濾鏡
* [內容]新拼花圖案濾波器
* [內容]新路面圖案濾波器
* [內容]新穿孔濾網
* [內容]新版 Splatter 濾鏡
* [內容]新紡織品磨損濾網
* [內容]新轉換濾波器

修正：

* [視窗]球面網格在 X 上鋪設 x2
* [視窗]載入自己環境時當機
* [視窗]環境地圖現在也使用曝光值
* [視窗]F快捷鍵不會重置攝影機角度
* [匯出]SBS 匯出可搭配最新的 Substance Designer 2018.3.3
* [出口]SBSAR 出口遵循與物質來源材料相同的指導方針
* [使用者介面]滾動條可以拖曳
* 支援在資料夾與檔案路徑上使用特殊字元
* 縮圖會在你儲存素材時重新生成

已知問題：

* 不建議在同一材料中使用多個 Delighters（甜點）
* Delighter 在較舊的 NVIDIA 驅動程式（低於 400.x）時會當機
* Delighter 階段的快速可見度切換會影響效能
* 自訂環境匯入可能會變成黑色
* Tif 影像在 Image 匯入圖層的屬性面板中沒有顯示
* 在滑桿中輸入特定值時，可以忽略逗點或點
* 預設儲存的收藏可以是空的
