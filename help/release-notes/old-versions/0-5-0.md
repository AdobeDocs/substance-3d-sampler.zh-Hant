# 0.5.0

上映日期： **2019/02/28**

補充：

* [圖層堆疊]圖層重排序
* [圖層堆疊]刪除隱藏圖層
* [圖層堆疊]直接匯入你選擇的位置的材質
* [圖層堆疊]材料輸入作為新的濾波參數類型
* [性能]Substance Engine 預算是動態的，以求更好的表現
* [效能]OpenGL 效能提升，尤其是在 MacOS 上
* [資料]新版本發布後資料升級速度更快
* [內容]AI Delighter 可在 Windows 7 和 Windows 8 上使用
* [內容]AI Delighter 可於 RTX GPU 上取得

修正：

* 修復關閉應用程式時可能發生的當機問題
* 匯出彈出視窗在匯出大型收藏時會開啟得更快

已知問題：

* 不建議在同一材料中使用多個 Delighters（甜點）
* Delighter 在較舊的 NVIDIA 驅動程式（低於 400.x）時會當機
* Delighter 階段的快速可見度切換會影響效能
* 載入自己環境時會當機
