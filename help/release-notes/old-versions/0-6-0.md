# 0.6.0

上映日期： **2019/04/18**

補充：

* [中繼資料]在專用分頁中查看並填寫材料的中繼資料
* [收藏]直接從搜尋結果建立收藏
* [媒體出版]匯出收藏版
* [使用者體驗]按 Ctrl+Z 來還原調整變更或匯入圖片
* [使用者體驗]按 Ctrl+Shift+Z 重新做調整變更或匯入圖片
* [使用者介面]新圖示與新風格
* [效能]新增會話管理器以更好地處理分頁切換
* [效能]影像匯入圖層開啟速度更快
* [內容]新金屬通用素材
* [內容]新 Rust 材料
* [內容]新石通用材料
* [內容]壓花濾網更新
* [內容]刺繡濾鏡更新
* [內容]油漆濾鏡更新
* [內容]Delighter 濾網更新

修正：

* [內容]水過濾器正在使用鏡面/光澤的工作流程
* 修正啟動彈窗中的灰階無線電按鈕
* 接受包含逗號字元的檔案
* 修正彈出視窗中小字型問題
* 修正因部分 NVIDIA 顯卡 FXAA 參數衝突而導致透明度介面問題
* 在滑桿中entenping值後，移除欄位的焦點
* 將最少的 VRAM 分配給 Delighter，以減少當機
* 修正調整應用程式視窗大小時的視窗凍結問題
* 在評估時刪除圖層堆疊時，已修正當機

已知問題：

* 不建議在同一材料中使用多個 Delighters（甜點）
* Delighter 在較舊的 NVIDIA 驅動程式（低於 400.x）時會當機
* 不建議快速切換 Delighter 舞台
* 自訂環境匯入可能會變成黑色
* Tif 影像在 Image 匯入圖層的屬性面板中沒有顯示
* 在滑桿中輸入特定值時，可以忽略逗點或點
