# 版本 2020.3（2.3）

**Substance Alchemist 2020.3「Vermicelli」** 引入了新內容與工作流程，例如從單一圖片建立地圖集。 我們也提升了素材的縮圖品質，並將介面本地化為中文。

發行日期： *2020年10月26日*

## 主要特色

### 影像轉材質（AI 驅動）

* 新參數
  * 透過調整不同細節層級（微、中、大）來細化你的幾何體（法線和高度通道）
  * 調整愉悅度，讓部分資訊保留在你的底色中
  * 可利用變異與柔度參數來產生更精確的粗糙度通道
* Nvidia RTX 3000 系列支援

![](../../assets/materia.jpg)

### Atlas Creation 工作流程

透過新增兩個濾鏡，從單一圖片製作圖譜在《物質煉金術師》中變得更為簡化。

Atlas 產生器：濾波器會自動從基底色產生不透明度通道。 它也會在底色上產生色彩擴散。 建議使用背景均勻的影像。

圖譜分離器：這個過濾器讓你能分離出圖譜中的特定元素並重新調整大小。

![](../../assets/atlas.jpg)

### 縮圖

縮圖現在是透過 Substance Designer 的 PBR 渲染節點，搭配新的環境貼圖 Studio\_06 生成的。

如果縮圖嵌入在 Substance 檔案檔（\*.sbsar）中，Substance Alchemist 現在會讀取縮圖，且不會重新生成。

![](../../assets/screenshot-new-thumbnails.jpg)

偏好設定中新增了一個參數，可以更改縮圖品質以節省時間。 預設情況下，畫質設定為高。

### 中文本地化

《物質煉金術師》現已本地化為中文版本。 你可以在偏好設定中更改介面語言。

![](../../assets/screenshot-chinese.jpg)

### 新增與更新內容

* **技術濾波器**

Warp：透過Warp你的素材來打破模式或讓素材更鮮明。

表面浮雕：為材質增加浮度和變化（更換高度調節濾波器）

反轉：反轉你選擇的頻道

* **風化濾網**

刮痕：在材料上加上刮痕。 例如對木材和金屬很有用。

指紋：在金屬或閃亮材質上留下指紋。

丟棄的口香糖：將舊口香糖散落在地上

* **色彩濾鏡**

上色：調色部分或全部材質

色彩變化：現在讓你可以選擇如何分割你的素材。 除了底色外，你還可以使用高度、環境遮蔽、金屬感和粗糙度。

替換顏色：在 2D 視圖中選擇一個顏色，然後再選擇新的。
