# 版本 3.4

**Substance 3D Sampler 3.4.0** 引入了一系列新功能，旨在提升 3D 工作流程的速度與品質。

*上映日期：2022年9月6日*

## 主要特色

## 暴露參數

在任何支援 SBSAR 檔案的軟體中修改參數材質，例如 CLO、UE5、Blender、Photoshop 和 Illustrator 等。\
這現在得益於 Sampler 新推出的資產參數公開功能，讓你能加快迭代，並消除 Sampler 與其他軟體之間的來回。

只要點擊一個釘選，就能顯示你素材的參數。

色點能幫助你辨識曝光參數和不同的面板。

## Python 撰寫

你現在可以建立外掛和腳本，這讓你能自訂介面，讓你輕鬆將 Sampler 整合進你的工作流程，並以任何你想要的方式設定整體工作流程。\
例如，這可以讓你建立腳本，讓你自動化重複性工作，例如一鍵匯出多個材料。

在這裡了解如何建立你的第一個外掛或腳本[&#128279;](../scripting-and-development/scripting-and-development.md)。

## CLO 物理性質

你現在可以用物理模擬創造出行為真實的紡織品。 這是透過輸入織物的物理特性來達成，例如彎曲、剪切和摩擦。\
透過這次更新，SBSAR將包含物理資訊於其元資料中，CLO會利用這些資料確保材料反應真實。

## 影像轉材質（AI 驅動）

影像轉材質（AI 驅動）現已在 MacOS 上提供，並能原生運行於 Apple Silicon 裝置。
