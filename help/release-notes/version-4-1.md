# 版本 4.1

<b>Substance 3D Sampler 4.1.0 </b>引入了 Paint Warp </b>濾鏡和改良版<b>刺繡</b>濾鏡的新內容<b>。這次更新包含了一些 3D 捕捉的改進。

*發行日期：2023年3月28日*

## 畫紋扭曲

Paint Warp 濾鏡讓你可以透過在 2D 視圖上畫曲線來扭曲材質。\
Straighten選項可以讓你重新對齊材質，讓平鋪流程變得輕鬆無縫。

## 刺繡

新的刺繡產生器讓你能從單一影像向量檔或圖畫中製作刺繡補丁。\
它能刺繡多達6種顏色，並結合多種縫紉技術。
