# 版本 6.0

墨西哥辣椒

![替代文字](../../help/assets/Sampler_splash_large.jpg)

此更新引入業界標準的 OpenPBR 支援、材質預設以加速進階材質的建立，以及重新設計的屬性面板，讓創作更靈活。

主要新功能包括：

## Substance 生態系統核心的 OpenPBR

Sampler 6.0 採用 [了業界統一的材質模型 OpenPBR](../features-and-workflows/openpbr.md)。 打造在更廣泛 3D 生態系中原生理解的建構材料：一個標準且無限的相容性。一次設計，消除猜測，並以打造跨工具無縫互通的模式加速工作流程。

![Substance 3D 取樣器中的 OpenPBR 材質標準](../../help/assets/OpenPBR_1820x1024.jpg)

## 一鍵就能掌握複雜材料

立即創造出更豐富且複雜的材料。 像是模糊、半透明和透明塗層等新模板，讓你能在不複雜的情況下加入進階物理效果。 只要選一個範本，然後開始！

更多資訊 *[請見此處](../interface/tools-and-widgets/material-creation-presets.md)*

![替代文字](../../help/assets/Sampler_Complex_Materials.jpg)

## 為材料創造而建

Sampler 6.0 將整個體驗優化為最重要的事：打造高品質的數位孿生素材。 每一次更新和新功能都旨在消除阻力，節省時間，讓你專注於真正能帶來價值的工作流程部分。

![替代文字](../../help/assets/Sampler_built_for_material_creation.jpg)

## 一個新的層疊，用於控制

掌控你的材料。 透過重新設計的屬性面板，你可以針對每個頻道設定濾鏡，讓你在不需額外步驟的情況下獲得精準編輯。

更多資訊 *[請見此處](../interface/panels/properties-panel.md)*

![替代文字](../../help/assets/Sampler_Infographic_1920x1080.png)

## 捕捉材料的速度比以往更快

Sampler 現在讓你只需一鍵啟動 HP Z Captis 的擷取，感興趣區域會自動偵測，且可隨選旋轉，並有智慧自動化對焦與光強，讓你用更少的設定獲得銳利且一致的地圖。

更多資訊 *[請見此處](../pipeline-and-integrations/hp-z-captis-support/your-first-capture-step-by-step.md)*

![替代文字](../../help/assets/Captis_capture_optimization.JPG)
