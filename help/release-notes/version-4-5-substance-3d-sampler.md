# 版本 4.5

<b>Substance 3D Sampler 4.5</b> 引入了第三方應用程式的 Send-to。

它允許一鍵將素材從 Sampler 傳送到第三方應用程式，避免手動匯出與匯入流程，避免浪費時間。

更多資訊 [請見此](../pipeline-and-integrations/substance-connector.md)處。

*上映日期：2024年7月10日*

![](../assets/connector-whatsnew.jpg)

## 發行說明

*（發行日期：2024年7月18日）*

<b>補充</b>：

* [互通性]將材質傳送到 UE5、Blender、Maya、3DsMax Unity
* [內容]新的貼圖產生器類別 - 漸層
* [內容]HDRI 工具 - 新的環境旋轉濾鏡

<b>修正：</b>

* [暴露參數]暴露 .sbsar 輸入值無法運作
* [層疊]底色在灰階影像中轉為紅色
* [渲染中]用於彩色通道的灰階影像色彩空間錯誤
* [腳本]使用匯出預設有時無法匯出預期的頻道
* [內容]Dirt - 在 Image to Material 上套用 Dirt 濾鏡會產生黑色法線
* [內容]壓印-在壓紋濾波器中，圖案的縮放在 0 與 1 之間並非線性
* [內容]讓它成為瓷磚——改善法線與高度一致性
