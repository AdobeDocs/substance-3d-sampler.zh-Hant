# 版本 4.0

使用 **Substance 3D Sampler 4.0**，你可以利用真實世界的影像製作 3D 物件，並具備自動主體遮罩、貼圖貼圖和幾何減量功能。 此版本引入了一些 UX 改進，作為 Python API 中的新功能。

*上映日期：2023年1月31日*

![](../assets/main-promo.jpg)

## 3D 擷取

有了 Substance 3D Sampler 4.0，你現在可以從影像中建立 3D 物件。

我們整合了攝影測量技術。 攝影測量是從影像中進行測量的技術過程。 這就是 Sampler 從一系列照片中建立 3D 網格的方式。

你只需要開始拍攝一系列捕捉物體可見表面的照片——智慧型手機或 DLSR 相機都很適合。

點此](../features-and-workflows/3d-capture.md)了解逐步工作流程[。

## 亮部

### 自動遮罩

移除你想 3D 捕捉的物體背景。 透過遮罩標籤匯入圖片後，建立物件的自動生成遮罩。

使用口罩有許多優點。 它能偵測特徵，並僅重建未遮罩區域。

![](../assets/release-page-masking.jpg){width="500px"}

### 定義你的重建區域

切換感興趣區域，在對齊影像後啟動邊界框。 設定並對齊你想重建的精確區域。

![](../assets/3d-capture-bounding-box-modified.png){width="500px"}

### 連接後製

當你的 3D 物件重建完成後，再用自動減模、UV 展開和烘焙來優化結果。

後製能幫助你根據需求和使用方式調整並優化網格和材質。

重建結果可以產生包含數百萬個多邊形和多達 16K 個貼圖的網格。 這通常不會針對渲染、即時或擴增實境體驗進行優化。

後處理步驟自動完成四個步驟：

* 大減
* UV 展開
* 重投影
* 烘焙

![](../assets/release-page-post-processing.jpg){width="500px"}

### 匯出至主要檔案格式

將重建的 3D 物件匯出成所有標準檔案格式，方便你在任何需要的地方使用。

![](../assets/v4-0-0-export.jpg){width="500px"}

## 視框

2D 與 3D 視窗可調整大小、交換及垂直堆疊。

![](../assets/screenshot-2023-01-25-at-16-23-09.png){width="500px"}

## 腳本編寫

我們將匯出功能拆分成四個：

* 出口資料： `export_material`
* 輸出環境燈： `export_environment_light`
* 匯出有無貼圖的網格： `export_mesh` 或 `export_3d_object`

我們新增了一個功能，可以匯入特定用途的材質： `import_textures`

Sampler 現在會在啟動時載入腳本，並將外掛儲存在由兩個環境變數定義的路徑上：

* `SAMPLER_PLUGIN_PATH`
* `SAMPLER_SCRIPT_PATH`
