# 版本 3.3

**Substance 3D Sampler 3.3.0** 引入了一系列新工具、內容與功能，讓製作與編輯材質與環境光源更為輕鬆。

*發行日期：2022年5月17日*

## 主要特色

## 內容感知填充

內容感知填充是 Adobe Photoshop 中流行的技術，用於去除照片中的細節，同時保持周遭區域的完整性。

Substance 3D Sampler 現在採用了同樣的技術，讓你能清潔 PBR 材質和環境燈。 在 PBR 材料中，內容感知填充會應用於所有通道。 不需要分別處理每個通道。

內容感知填充（Content-Aware Fill）能幫助去除大型元素，避免鋪磚時重複，或消除掃描布料上的細微瑕疵。

在拍攝 360 度全景時，你可能無法控制場景中的所有元素，因此需要移除地上的小物件、牆上的畫作或背景中的人物。 內容感知填充現在讓這件事變得更簡單。

## IBL 著作

### 球面投影

當環境燈和 360 度影像以一般影像顯示時，編輯它們可能會很有挑戰性。 所有元素都被扭曲，幾乎無法編輯。 有了新的球面投影，你可以在 360° 內導航，並使用專用工具如 Nadir Patch、Content-Aware Fill 以及所有程序燈光進行無失真編輯。 例如，現在編輯或清理直線、拆除相機三腳架，以及完美放置線條燈變得更容易。

看看使用這個新模式製作 [環境燈光](https://www.youtube.com/watch?v=cfW9IyoTXQ8) 的新教學。

### 曝光滑桿

在 2D 視圖中，你可以暫時調整曝光，幫助你更清楚地看到你正在編輯環境中曝光不足或過曝部分的細節或物件。

### 專用檢視器設定

檢視器的設定會依資產類型（材質光或環境光）持續存在。 你可以為每種資產類型設定網格、預設材質或攝影機視野，方便在適當情境下切換。

## 改良小工具

### 複製印章

透過這次 Clone Stamp 更新，你可以在單一圖層中繪製多筆圖，並取得圖層堆疊中的印章歷史。 另外，你現在可以在畫筆預覽中直接看到印章結果，然後再上色。 這讓材料清潔變得更容易，也避免了在不同視角之間來回切換的麻煩。

### 裁剪與轉化

此更新新增了裁切與變換小工具操作的捷徑。

### 筆刷工具列

新的使用者介面類似於最新的 Adobe 產品如 Fresco，允許你在 2D 視圖中任意移動工具列，無論是垂直或水平顯示。 上色時，可以用 E 鍵在刷子和橡皮擦間切換，並利用新的平鋪選項來更好地控制你畫的顏色。

## 影像轉材質（AI 驅動）

### 保留平鋪

影像到材質（AI 驅動）新增了選項：現在可以保留可鋪磚影像的平鋪，縮短後鋪材質的時間。

## 互通性

將資料寄給 Stager

當時已經可以向斯泰格傳送環境燈。 現在你可以像使用 Designer 和 Painter 一樣，一鍵將素材傳送到 Stager。 多虧了這個功能，你不再需要將材質發佈並以獨立檔案載入 Stager（需要 Stager 1.2.0 版本搭配新的材質管理器）。
