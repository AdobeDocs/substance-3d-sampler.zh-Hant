# 編輯 3D 捕捉網格

>[!WARNING]
>
> 自 Sampler 5.1 版本起，已移除對 3D 捕捉的支援。

## 編輯 3D 捕捉網格

在這份使用指南中，我們將介紹一些在 Substance 3D Sampler 中編輯與後製 3D 捕捉物件的技巧。

你比較喜歡把這部影片當作教學看嗎？ 你可以在這裡找到它 [。](https://youtu.be/6_EZEAR0Uy8?si=6AaCUHD6nnWZyKUE "進階 3D 擷取 - 網格後製教學影片")

![](../assets/post-processing-3d-capture.png)

完成 3D 捕捉過程並在 Sampler 專案中加入網格後，你可以對它進行修改。 這些可以是對網格或材質的變更。 網格濾波器是從 Sampler 4.0 開始新增的。 材質濾鏡會使用之前 Sampler 裡熟悉的濾鏡。

當你在 Sampler 編輯擷取的 3D 物件時， <b>你可以混合</b>堆疊 Mesh 和材質濾鏡，它們會自動套用到資料的正確部分。 快速篩選清單無法區分這兩種類型。

## 網狀濾波器

我們先來看看網狀過濾器。 Sampler <b>裡有兩個：網格轉換</b>和<b>網格後製。</b>

<b>網格變換</b> 是一個簡單的濾鏡，讓你能 <b>平移</b>、 <b>旋轉</b> 和 <b>縮放</b> 網格。 最常見的是翻轉物件，或調整它的比例。 任何掃描都會預先套用一個變形。

<b>網格後製處理</b> 與 3D 捕捉對話框末尾的後製步驟相同，但採用動態濾鏡。 它讓你能 <b>重新網格</b> 、 <b>重新UV</b> 和 <b>重新烘焙</b> 你的貼圖。 這個濾鏡的目的是透過 <b>減少三重數量、改善 UV 以及縮小</b>貼圖來優化你的網格。 使用它最棒的成果之一是改良的 UV 佈局。 預設的原始 3D 捕捉輸出 UV 非常碎片化，通常新的自動 UV 是改進。

它不是快速的濾波器，只要你改變參數，網格就會被處理。 最好對它有點耐心。

## 材料過濾器

材質過濾器種類多樣得多，任何能用在一般材質上的過濾器都可以用在 3D 捕捉網格的材質上，但要注意，結果不一定總是有效，因為許多過濾器是針對均勻且平鋪的材質設計的。

最實用的濾鏡通常是像是明亮 <b>對比</b>、 <b>色相飽和度</b>，以及一些進階的濾鏡，用於編輯通道。 由於無法捕捉到物件的粗糙度，我們將使用濾鏡將其恢復。

你可以用 <b>色相飽和度濾鏡</b> ，讓顏色更接近你物件的真實顏色。 有更好的色彩準確度，但比這個快速濾鏡複雜得多。

接著你可能想把原本存在於物體中的反射還原。 我們可以在這裡使用 <b>顏色替換濾鏡</b> 。 Color Replace 可以讓你從材質中擷取一個顏色，並用該顏色更換所有區域。

預設情況下，它會為你選擇的顏色中的所有顏色上色，但如果你開啟<b>進階分割</b>，然後設定為<b>從底色</b>遮罩並<b>以粗糙度</b>替換<b></b>，你可以讓所有選定顏色的區域粗糙度變得更光亮。調整亮度變化和遮罩範圍有助於微調遮罩。

最後，你可能想把底色的細節帶回粗糙度。 <b>頻道切換濾鏡</b>讓我能混合並混合不同頻道的細節。你可以把 <b>輸入設為 Basecolo</b>r， <b>輸出設為粗糙度</b>，然後調整混合模式和透明度，做出有趣且接近真實的效果。

最後，如果你想更精確控制最終的粗糙度，可以使用亮度對比濾鏡，並設定影響粗糙度通道。 然後你調整數值，讓粗糙度稍微更酥脆一點。

每個物件都不同，根據你的資料集，可能需要做特定的調整。 你甚至可以使用 <b>複製印章工具</b> 來擦除想要移除的材質部分，例如捕捉輔助標記。 只要記得，任何使用材質特定位置的材質濾鏡都會依照你的 UV 配置而定，所以在使用材質濾鏡之前，先做網格處理。

當你對物件和材質滿意後，可以用<b>「分享」>「另收成」</b>對話框匯出</b>結果<b>。一般設定讓你選擇名稱和路徑，網格設定可以選擇 3D 網格格式，材質設定則是設定網格材質。 你可以關閉網格或材質，只匯出其中一個。 匯出完成後，你的網格就可以用於其他 3D 應用程式。
