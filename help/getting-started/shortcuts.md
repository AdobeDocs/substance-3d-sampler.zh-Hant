# 捷徑

本頁列出所有可用的鍵盤快捷鍵及其操作。

## 全球捷徑

| *行動* | *窗戶* | *MacOS* |
| --- | --- | --- |
| 還原 | Ctrl + Z | ⌘ + Z |
| 取消復原 | Ctrl + Shift + Z | ⌘ + Shift + Z |
| 儲存 | Ctrl + S | ⌘ + S |
| 另存新檔 | Ctrl + Shift + S | ⌘ + Shift + S |
| 匯出 | Ctrl + E | ⌘ + E |
| 僅3D視圖 | 3 | 3 |
| 僅限 2D 檢視 | 2 | 2 |

## 3D 視圖捷徑

| *行動* | *窗戶* | *MacOS* |
| --- | --- | --- |
| 攝影機旋轉 | Alt + 滑鼠左鍵或滑鼠左鍵 | 選項 + 滑鼠左移或滑鼠左移 |
| 鏡頭平移 | Alt + 滑鼠中間或滑鼠中間 | 選項 + 滑鼠中間或滑鼠中間 |
| 相機變焦 | Alt + 滑鼠右鍵或滑鼠滾輪 | 選項 + 滑鼠右鍵或滾輪 |
| 焦點 | F | F |
| 環境旋轉 | Shift + 滑鼠右鍵 | Shift + 滑鼠右鍵 |
| 環境可視性 | 1 | 1 |
