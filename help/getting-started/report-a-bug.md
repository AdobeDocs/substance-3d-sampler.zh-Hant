# 回報錯誤

你可以在 Sampler 裡面回報錯誤。

打開<b>說明</b>選單，然後選擇<b>「檢舉」</b>

![](../assets/Bug-report-howto.png.img.png){width="700px"}

請填寫以下表格：

![](../assets/Bug-report-window.png.img.png){width="400px"}

然後按下提交鍵。 您輸入的資訊將直接與 Sampler 開發團隊分享。
