# 進口資源

Sampler 可以利用外部資源，如圖片和 Substance 檔案來修改你的專案。 請使用以下任一選項將檔案匯入您的專案：

* 將檔案從檔案總管拖放到取樣器視窗。 會跳出匯入視窗，選項可以更改匯入處理方式。

![](../assets/importing-resources-Importwindow.png)

* 從 <b>左側列</b>使用 <b>「取得內容 </b>」按鈕，然後選擇 <b>「匯入圖層堆疊</b>」或 <b>「匯入你的資產</b>」。 這兩個選項都會開啟檔案總管，讓你可以瀏覽並選擇要匯入的檔案。
  * <b>在 Layer Stack</b> 匯入會匯入你目前專案的檔案。
  * <b>匯入你的資產</b>會匯入檔案，讓任何專案都能存取。

![](../assets/Project_CreateNew.png)

* 在 <b>圖層</b>面板中，如果還沒有建立圖層，你可以利用可用的連結匯入檔案，作為材質的基礎。

>[!NOTE]
>
> 資源是連結的，而非匯入的。 因此，如果資源檔案被移動或刪除，使用該資源所建立的材料或內容也會受到影響。 因此，我們建議使用專門的資料夾來存放取樣資源。
> 
> 預設情況下，Sampler 所包含的素材會儲存在 C：\Program Files\Adobe\Adobe Substance 3D Sampler\Resources\assets 下

## 支援的檔案格式

| 類型 | 說明 |
| --- | --- |
| <b>點陣圖/圖片</b>  （JPEG、PNG 等） | 你可以在圖層</b>面板拖放或匯入點陣<b>圖，或進入 SBSAR 或允許輸入圖片的濾鏡參數。 |
| <b>物質套裝</b>  （SBSAR） | 你可以將 SBSAR 檔案匯入到 <b>資產 </b>面板或 <b>圖層 </b>面板。 |
