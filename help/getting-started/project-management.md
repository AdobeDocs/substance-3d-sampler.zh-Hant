# 專案管理

在 Substance 3D Sampler 裡，你可以用集合管理所有資產和材質。 專案是組織資料的好方法。 專案可以匯出或匯入，方便在不同電腦間共享。

## 建立一個新專案

要建立新專案，請在<b>主畫面選擇<b>「建立新</b>專案」或<b>>新專案</b></b>檔案。建立新專案會啟動快速啟動對話框，您可以選擇快速動作或匯入圖片或 Substance 檔案來開始您的專案。

![](../assets/6.0_HomeScreenFocus.png)

或者，你也可以用 <b>快速開始</b>按鈕直接跳進一個空白專案。 你仍然可以根據需要手動匯入資產和內容。

點擊「建立新」按鈕後，專案會自動開啟並命名為「*Untitled Project\**」，直到你儲存專案為止。 你可以在專案面板</b>中用高亮的<b>新增資產按鈕</b><b>，將資產加入你的專案。

![](../assets/Project_CreateNew_1.png){width="600px"}

## 拯救專案

要儲存專案，請使用 <b>檔案>儲存 </b>或 <b>另存為</b> 選單操作。 這會開啟一個對話框，讓你選擇使用哪個名稱以及將專案檔案儲存在哪裡。

或者你也可以用快捷鍵 <b>Ctrl + S</b> 來<b>儲存</b>，或<b>用 Ctrl + Shift + S</b> 來儲存<b>新檔。</b>

儲存的專案會以名為 <b>YourProject.ssa</b> 的檔案形式出現。 SSA 是 samplers 檔案格式，用來儲存關於你專案及其可能依賴的資訊。

## 開啟現有專案

專案可透過幾種方式開啟：

* 在 <b>主畫面</b>：使用最近專案清單，雙擊快速開啟專案。
* 在主畫面</b>：<b>點擊<b>「開啟</b>」開啟檔案瀏覽器，您可以選擇想開啟的檔案。
* 透過 **檔案>開啟專案** 選單。
