# 製作進階材料

使用 [OpenPBR](../openpbr.md)，你可以透過使用模糊（fuzz[&#128279;](fuzz.md)）、[次表面（subsurface](subsurface.md)）和[塗層（coating](coating.md)）等通道來創造有趣的效果。這些通道通常只在特定情境中使用，且與常見通道如粗糙度或底色有些不同。

- [失真](fuzz.md)
- [地下](subsurface.md)
- [塗層](coating.md)
