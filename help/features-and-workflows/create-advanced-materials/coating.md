# 處理塗層通道

顧名思義，塗層通道可以讓你在材料上加塗層。 塗層本身可能有其粗糙度值，這會影響材料的基底粗糙度，有助於創造如清漆或拋光表面的效果。 請觀看下方影片，了解如何使用Sampler的塗層通道，從零開始製作上漆拼花地板材料。
