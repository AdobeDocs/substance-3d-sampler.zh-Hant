# 效能模式

效能模式整合了所有可能拖慢工作流程的設定：解析度限制、陰影、位移品質與路徑追蹤。 關掉不需要的部分，這樣就能獲得你想要的反應速度，尤其是在較輕的硬體上。

>[!NOTE]
>
> 若您的硬體未達到 Sampler 的 [最低需求](../getting-started/system-requirements.md)，效能模式會自動開啟並設定最大限制。 這使得在性能較弱的硬體上仍能繼續使用 Sampler 成為可能。

## 切換效能模式

效能模式可透過&#x200B;**取樣器視窗**&#x200B;右上角&#x200B;**的效能模式按鈕**&#x200B;切換。

![](../assets/performance-mode-button.png)

## 變更效能模式設定

使用效能模式按鈕&#x200B;**旁**&#x200B;的下拉選單來控制效能模式所啟用的限制。

![](../assets/performance-mode-settings.png)

| 背景設定 | 說明 |
| --- | --- |
| **最大預覽解析度** | 效能模式會降低預覽解析度以加快渲染速度。 這不會改變匯入資產或文件的解析度;相反地，這會改變視窗渲染器的品質。 |
| **停用位移品質** | 啟用此設定時， **效能模式** 會將 **位移品質值** 鎖定為 0，並停用視窗中的位移效果。 對於光滑的材料如瓷磚或細緻織物，這種方式對視覺影響很小，但能大幅提升性能。 |
| **停用陰影** | 網格與位移材質會投射陰影，以犧牲效能為代價，創造更逼真的影像。 啟用 **「停用陰影」** 時，效能模式會關閉所有陰影處理，提升效能。 |
| **停用路徑追蹤** | 路徑追蹤是一種強大的渲染方法，能追蹤光線路徑在場景中反彈，創造出逼真的渲染效果。 然而，路徑追蹤成本較高。 當&#x200B;**「停用路徑追蹤**」開啟時，效能模式會停用在 3D 視窗&#x200B;**中**&#x200B;啟用路徑追蹤的選項。 |

>[!NOTE]
>
> 路徑追蹤可從 **3D 視窗工具列**&#x200B;存取。
>
> ![](../assets/enable-path-tracing.png)
>
> 若未啟用路徑追蹤，啟用效能模式且僅 **開啟「停用路徑追蹤** 」將無效。
